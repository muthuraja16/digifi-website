DIGIFI LOGO FILES
=================

Colors
  Navy           #0A1340   wordmark, tile
  Electric blue  #0064F8   rising dots
  Tile on navy   #131E57   symbol tile on dark backgrounds
  Tagline (dark) #A9B4D6   tagline on navy backgrounds

Typeface
  Wordmark: Bricolage Grotesque ExtraBold (800), outlined to vector paths
  Tagline:  Bricolage Grotesque Medium (500), outlined to vector paths
  (No font installation needed: all text is already converted to shapes.)

Files
  digifi-logo-horizontal-light.svg / .png     Symbol + wordmark + tagline, for white or light backgrounds
  digifi-logo-horizontal-reversed.svg / .png  Same, for navy or dark backgrounds (white letters)
  digifi-wordmark-light.svg / .png            Wordmark + tagline only: website header, visiting cards, letterheads
  digifi-wordmark-reversed.svg / .png         Same, for dark backgrounds
  digifi-symbol.svg                           Symbol tile: social avatars, app icons, stickers
  digifi-symbol-on-navy.svg                   Symbol tile for use on navy backgrounds
  favicon.svg, favicon-16.png, favicon-32.png Website favicon (squares enlarged for small sizes)
  apple-touch-icon-180.png                    Phone home-screen icon
  icon-512.png                                Large icon (social profiles, Google Business Profile)

Usage
  - SVG files are the masters: use them for the website, print and signage.
  - PNG files are for places that don't accept SVG (WhatsApp, social media, documents).
  - Keep clear space around the logo of at least the width of one blue dot.
  - Do not recolor, stretch, rotate, add shadows or gradients, or change the dot positions.
